# Grafana Issues

## Dashboard Issues

### Dashboard Not Loading

1. Check dashboard JSON syntax
2. Verify data sources are configured
3. Check query syntax
4. Verify time range

### No Data in Panels

1. Verify data source connection
2. Check query syntax
3. Verify time range
4. Check if data exists for the time range

### Panel Errors

1. Check panel configuration
2. Verify query syntax
3. Check data source permissions
4. Review panel logs

## Data Source Issues

### Connection Failed

1. Verify service is running
2. Check service URL
3. Verify network connectivity
4. Check authentication credentials

### Query Timeout

1. Optimize query
2. Reduce time range
3. Add query limits
4. Check service performance

## Alert Issues

### Alerts Not Firing

1. Verify alert rule configuration
2. Check query syntax
3. Verify threshold values
4. Check alert evaluation interval

### Webhook Not Working

1. Verify webhook service is running
2. Check webhook URL
3. Verify network connectivity
4. Check webhook service logs

## Permission Issues

### Cannot Edit Dashboards

1. Check user permissions
2. Verify dashboard ownership
3. Check folder permissions
4. Review Grafana logs

### Cannot Access Data Sources

1. Check data source permissions
2. Verify user role
3. Check organization settings
4. Review access logs
